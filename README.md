# 医学生自救计划

## 项目介绍

在医疗系统逐步腐烂的当下，希望这个项目能帮助一部分医学生/计算机初学者找到出路，预计知识面将涵盖互联网开发、原生开发、深度学习、机器学习、硬件开发、嵌入式等的基础知识，起到帮助入门的作用

**26.3.19review：**确实是入门哈，例如前端介绍的HTML+CSS+JS都是上个世纪的技术栈了，只能说是作为基础中的基础，现代的网页开发基本上都是B/S架构，只学这仓库的HTML+CSS+JS连面试都过不了吧
关于R语言的部分，可以看看GitHub上更全面的仓库介绍（high stars），如EasyChart/Beautiful-Visualization-with-R《R语言数据可视化之美》配套代码，etc

## 使用方法：

将这个文档拖进各种ide，这里推荐visual studio，加载完成后，左侧会显示文件结构，可以在此处选择自己希望访问的文件并进行编辑
